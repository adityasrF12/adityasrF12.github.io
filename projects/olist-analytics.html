Olist E-Commerce Analytics

Snowflake • SQL Optimization • Power BI • ETL Pipelines

The Objective

Building an end-to-end data pipelines and business dashboard to analyze sales growth and shipping performance.

This project focuses on processing, structuring, and visualizing the Brazilian e-commerce Olist dataset, which contains over 100,000 order records. The main goal was to organize fragmented marketplace data into a centralized data warehouse to easily track revenue, seller performance, and shipping delays.

Interactive dashboard built inside Power BI to track monthly sales revenue, shipping delays, and order distributions across regions.

Technical Stack

Snowflake, SQL, Power BI, Data Modeling, ETL Pipelines.

Key Highlights

  • • Logistics Metrics: Created calculations to track shipping times and pinpoint exact regions experiencing severe delivery delays.
  • • Sales Analysis: Wrote complex SQL queries to track Year-over-Year revenue growth, active customer counts, and merchant sales trends.
  • • Dashboard Design: Developed an interactive reporting system that allows teams to quickly filter data by location, dates, and order status.

Data Ingestion & Modeling

I loaded the raw datasets into Snowflake and used structural SQL queries to clean and organize the relational tables. By setting up analytical schemas separate from transactional entries, query performance improved drastically, allowing the reporting dashboard to pull updates quickly without computing lags.

Logistics & Supply Chain Analysis

A key focus area was analyzing shipping data to find delivery issues. I structured specific data fields to measure tracking times against the estimated arrival dates. By matching these numbers against regional seller codes, the dashboard clearly points out exactly which logistics hubs or routes run into frequent delays.

"Organizing data correctly in the warehouse is essential for accurate business insights. Cleaning relational tables ensures your business reports run smoothly and stay consistent over time."

Interactive Business Intelligence

The final interactive dashboard was developed using Power BI. Instead of displaying static graphs, the interface allows business users to quickly explore sales performance. Users can slice metrics by customer regions, payment preferences, or specific product categories to make immediate data-driven adjustments.
