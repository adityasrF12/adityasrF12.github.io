Google Merch Recommendation

Big Data • Collaborative Filtering • Scalable Machine Learning

The Objective

Developing a personalized recommendation system using Alternating Least Squares (ALS) to handle sparse user-item matrices at scale.

In the landscape of e-commerce, personalized suggestions are essential for engagement. This project utilized the Google Merchandise dataset to build a recommendation engine that utilizes implicit feedback, transforming raw user interactions into high-fidelity product suggestions through distributed computing.

Model RMSE 0.122
Baseline RMSE 0.343

A significant improvement over the baseline indicates the model's effectiveness in capturing latent user preferences.

Technical Stack

PySpark, ALS Algorithm, Python, SQL, Apache Spark.

Methodology

  • • Implicit Feedback: Calculating interaction weights based on user action types and categories.
  • • Matrix Factorization: Breaking down user-item matrices into latent factors.
  • • Cold Start Strategy: Implementing robust drop-strategies for new user data.

Implicit Feedback and Feature Engineering

Unlike explicit ratings, user behavior on the Google Merch store provides implicit feedback. I calculated interaction weights by grouping data by action type, category, and country. These counts were normalized against the global maximum to ensure interactions with lower frequencies contributed proportionately to the ALS model.

Collaborative Filtering via ALS

The Alternating Least Squares algorithm was selected for its ability to handle sparse user-item matrices and scale effectively using PySpark. By decomposing the interaction table into latent user and item factors, the system successfully identified underlying patterns in purchasing behavior.

"The model achieved an RMSE of 0.122, a substantial improvement over the baseline of 0.343, proving the system's effectiveness in capturing personalized preferences."

Recommendation Generation

The final engine generates the top personalized recommendations for each user. To ensure relevance, a post-processing filter removes items the user has already purchased from their final suggestion list.
