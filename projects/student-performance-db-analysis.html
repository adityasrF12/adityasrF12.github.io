Database Systems & Analysis

Relational Modeling • SQL Optimization • ETL Pipelines

The Objective

Transforming raw socioeconomic datasets into a normalized relational architecture to identify drivers of academic success.

Data without structure is noise. In this project, I engineered a complete end-to-end database solution—from raw CSV ingestion and Python-based ETL to a fully normalized PostgreSQL schema. The goal was to build a resilient system capable of performing complex analytical queries on student performance indicators, such as parental involvement, attendance, and internet access.

3NF Normalized Schema illustrating relationships between Students, Parental Details, and Academic Performance.

Technical Core

PostgreSQL, SQL, Python (Pandas), ETL, Performance Tuning.

Engineering Specs

  • • Normalization: 3rd Normal Form (3NF) to ensure data integrity and reduce redundancy.
  • • Optimization: Custom B-Tree indexing for high-frequency analytical queries.
  • • ETL: Automated Python scripts for data cleaning and relational segregation.

ETL & Data Segregation

The pipeline began with a custom Python ETL suite designed to clean and validate raw student records. Using regular expressions and validation logic, the script handled inconsistent casing and out-of-range values before segregating the flat file into four distinct relational tables: Students, ParentalDetails, SchoolAcademicDetails, and SubjectScores.

Query Performance Optimization

To support real-time diagnostic reporting, I implemented advanced SQL optimization techniques. By creating strategic B-Tree indexes on high-cardinality columns like `attendance` and `student_id`, I significantly reduced execution time for complex JOIN operations involving academic performance and socioeconomic indicators.

"A well-optimized database is the silent engine of any AI system. By focusing on normalization and indexing, I built a foundation that turns raw records into actionable insights."

Diagnostic Analytics

The final system enables deep-dive diagnostic queries, such as correlating low attendance (<50%) with specific subject score categories. This allows for the identification of at-risk students through automated SQL reporting, providing a scalable model for educational intervention strategies.
